\section{Reproduction}\label{app:reproduction}
\paragraph{Experiment directories.}
v1: \texttt{symmetry\_composability\_v1}; v2--v7: \texttt{composability\_mechanisms\_v1} to \texttt{composability\_mechanisms\_v6} (the directory index is one below the round). Each
holds the verbatim plan, \texttt{protocol.json} and \texttt{protocol\_lock.json}, the deviations, the run ledger, the report, and the
results (decoded chains as compressed shard archives).

\paragraph{Paper build.}
\texttt{paper/REPRODUCE.md} is generated by \texttt{paper/scripts/reproduce\_md.py}. It lists the command for every figure, table and
number with the SHA256 of each input, and the lock commit of every round. All numbers in the text are macros produced by
\texttt{paper/scripts/build\_claims.py} from the locked results; \texttt{paper/check.py} verifies, before every commit, that each macro
is defined, that each cited claim exists in \texttt{paper/claims.yaml}, that each confirmed claim cites a locked prediction, and that no
bare decimal number appears in the text.
