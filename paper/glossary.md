# 术语表 / Glossary（PLAN A6；统一用法）

| English | 中文 | 定义（简） |
| --- | --- | --- |
| decodable | 可解码 | 编辑后的潜变量一步解码即得到正确文本（R\_1 高） |
| composable | 可组合 | 连续施加编辑，整条链在每一步都解码正确（R\_k 随 k 保持高） |
| instruction write | 指令写入 | 编辑器写入的是"让解码器执行某个运算"的指令，与源状态无关（CE 编辑器） |
| state write | 状态写入 | 编辑器把槽位改写成目标状态的规范表示 |
| slot | 槽位 | 承载属性值（状态词）的编码器 token 位置 |
| harmonic plane | 谐波平面 | 槽位表示中第 k 个傅里叶频率张成的二维（或一维）子空间 |
| fundamental | 基频 | k = 1 的谐波平面，携带全局位置 |
| frozen plane | 冻结平面 | 冻结手术中保持不变（停在起点）的平面 |
| revival | 复活 | 冻结基频时单向链在 t = N（转满一圈）处重新正确 |
| readout | 读出 | 从槽位表示得到状态的规则（多尺度最近状态的投票模型） |
| drift | 漂移 | 连续编辑中潜变量偏离规范表示的累积误差 |
| margin | 余量 | 读出时正确状态与最近竞争状态的分差 |
