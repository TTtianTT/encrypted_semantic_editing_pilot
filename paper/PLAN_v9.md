## 2. P9：只用 CPU 的分析（探索性，锁定前完成；结果直接供论文使用）

- **P9a 写入几何（M3）**：对象是现有的 C1 编辑器（v5 的 BART、T5Gemma 2B-2B，以及 v8 的自然文本 C1\_nat）。
  - **写入的统计量**：写入向量的范数；跨源状态的方差占比（1 − 残差方差 / 总方差，衡量写入"有多接近常数"）。
  - **零基线**：
    - 与规范写入的 cosine，和"随机方向与规范写入的 cosine"分布比较；
    - 再和"同一编辑器在另一域上的写入"作匹配对照。
  - **状态探针**：在干净编码上训练状态分类器（按 world 划分 train/test），作用于第 1 步编辑后的槽位，报告读出源状态、目标状态、其他状态的比例。
- **P9b 循环结构（M4）**：
  - 每个谐波平面中 N 个状态坐标的椭圆度（两奇异值之比），以及相邻状态角度相对 2πk/N 的偏差。
  - 前几个平面在中心化槽位码方差中的占比。
  - 对照：用 v2 的乱序映射 σ\_max 重新标记状态，计算同样的统计量。
  - 范围：BART 与 T5Gemma 2B-2B 的 weekday、month 模板 0；自然文本 month；9B-9B 的 month。
- **P9c 预测器（M5）**：
  - 对 v5 L、v8 N5、v8 G5，给出"预测器一致率 − 每格多数参考"的 world 级 bootstrap CI；逐格与逐 world 分开报告。
  - 学习基线：用廉价的潜空间特征（第 1 步槽位到目标干净编码的距离、槽位范数、第 1 步余量 m、ρ）训练逻辑回归，按 world 交叉验证。
  - 简单规则："只看第 1 步潜空间读出"。
  - 特征缺失的轮次，在 CPU 上重算 BART；T5Gemma 用已缓存的编码。实在算不了的，记录原因。
- **P9d（M6）**：在全部 CE 格子中，第 1 步槽位读出等于起点的 world 比例。这一项直接测"写指令"，不依赖训练族标签。
- **P9e（M7）**：根据 git 历史生成各轮的时间线表，列出锁定提交、锁定前已看到的结果、锁定后的修订，以及哪些设计改动来自上一轮的失败。供附录 A 的"先定了什么"叙述使用。

## 3. B：基线（GPU）

- **范围**：BART-base 与 T5Gemma 2B-2B，weekday 与 month，模板 0；B4 的范围单独说明。
- **链**：plus、minus 与交替三种路径，单向 2N 步；B4 走 4N 步。

### B1 steering 向量（审稿意见中"最自然的基线"）

| 编辑器 | 定义（附录 A.1） | 预测 | 对立 |
| --- | --- | --- | --- |
| **B1a 全局均值差** | 每个位置加同一个向量：对 train 中全部 world 与全部状态，取 E(x+1) − E(x) 的均值 | **H-cancel**：R\_1 ≤ 0.20（在一圈上取平均时，状态分量互相抵消） | H-shift：R\_1 ≥ 0.80 |
| **B1b 单对均值差** | 只用一对状态 x₀ → x₀+1 的均值差（ActAdd 式对比对） | R\_1(起点 = x₀) ≥ 0.80，且其他起点的平均 R\_1 ≤ 0.20；全体 R\_2 ≤ 0.20 | 其他起点的平均 R\_1 ≥ 0.50 |
| **B1c 按读出索引的均值差** | 每一步先用潜空间读出 ŷ，再加上状态 ŷ 的均值差 | **H-state-aware**：单向 R\_2N ≥ 0.90 | ≤ 0.50 |

读法：常数写入无法实现循环上的一步；写入一旦依赖读出的状态，就能组合。B1c 不是仿射映射，在论文中标为"状态感知的 steering"。

### B2 LoReFT（ReFT 家族；Wu et al., NeurIPS 2024）
- **参数化**：h ← h + Rᵀ(Wh + b − Rh)，R 的 16 行正交，作用于全部 token。
- **两种训练**：
  - **LoReFT-C1**：一步 CE，与 C1 相同；
  - **LoReFT-C3U4**：与 C3-U4 相同。
- **seed**：45–47。
- **预测**：
  - **H-objective**：LoReFT-C1 的 R\_1 ≥ 0.90、R\_2 ≤ 0.20、D ≥ 0.80；LoReFT-C3U4 的 R\_2N ≥ 0.95。
  - **对立 H-param**：LoReFT-C1 的 R\_2N ≥ 0.90。

### B3 容量
- **编辑器**：满秩残差线性映射（d × d，零初始化），以及 MLP 残差（h + W₂·GELU(W₁h + b₁) + b₂，隐藏维 = d）。都用一步 CE 训练，seed 45–47。
- **预测**：
  - **H-objective**：两者都满足 R\_2 ≤ 0.20 且 D ≥ 0.80。
  - **对立 H-capacity**：R\_2N ≥ 0.90。

### B4 展开视野
- **编辑器**：只用 CE、不加 L2 的展开训练，rank-16 编辑器：
  - U8：S ≤ 8；
  - U16：S ≤ 16；
  - Urand：S 在 1 到 2N 之间均匀抽取。
- **范围**：BART 的 weekday 与 month；T5Gemma 2B-2B 只做 month 的 U8。seed 45–47。
- **评测**：R\_{S\_max + 2} 与 R\_4N。
- **预测**：
  - **H-counter**：U8、U16 的 R\_{S\_max+2} ≤ 0.50，Urand 的 R\_4N ≤ 0.50。
  - **对立 H-state**：任一编辑器的 R\_4N ≥ 0.90。
- **注意**：如果 Urand 成立 H-state，这是一个正面结果——"足够长、足够随机的展开能让 CE 学会写状态"，论文 §5 要据此改写。

### B5 解析旋转编辑器（检验谐波描述是否充分）
- **做法**（附录 A.4）：只作用于槽位。
  - 在每个谐波平面里，用该 world 干净码的二维协方差做白化，旋转 ±2πk/N，再反白化；
  - 平面之外的分量不变；
  - 不用任何转移对来拟合。
- **说明**：它用到 world 的干净编码，与预测器的读出相同，在论文中标为诊断。
- **范围**：模板 0 的 weekday、month（两个骨干），以及自然文本 month（两个骨干）。
- **预测**：
  - **H-sufficient**：单向 R\_2N ≥ 0.95。
  - **对立**：≤ 0.50。

### B6 解码后重编码（参照，不是预测）
- **做法**：每步解码，再重新编码。
- **报告**：R\_2N，以及每步的墙钟时间，与潜空间算子对比。放进表 1，作为"能解码时的现实替代方案"。

## 附录 A：定义

### A.1 均值差向量（模板 0，位置对齐）
- **全局均值差（B1a）**：对每个位置 i，Δᵢ = 均值\_{w, x}[E\_w(x+1)ᵢ − E\_w(x)ᵢ]，在 train 的全部 world 与全部状态上取平均。minus 方向取 −Δ。
- **单对均值差（B1b）**：只在 x = x₀ 上取平均，x₀ 为状态 0。
- **按读出索引（B1c）**：每步先用锁定的读出得到 ŷ，再加上 Δ(ŷ) = 均值\_w[E\_w(ŷ+1) − E\_w(ŷ)]，作用于全部位置。

### A.2 LoReFT
h ← h + Rᵀ(Wh + b − Rh)，R ∈ ℝ^{16×d} 的行正交（用正交参数化保持），W ∈ ℝ^{16×d}，b ∈ ℝ^{16}。训练设置同对应的 C1 与 C3-U4。

### A.3 随机视野展开（B4 的 Urand）
每个 batch 从 {1, …, 2N} 中均匀抽一个 S，用 CE 在全部 S 步上监督（同 v4 的 U 设定），不加 L2。更新次数与 U16 相同。

### A.4 解析旋转（B5）
1. 对 world w 的干净槽位码，求中心 μ\_w 与平面基 B\_k（同 v3 附录 A.1）。
2. 在平面 k 中，取二维坐标 z = B\_kᵀ(h − μ\_w)，以及该 world N 个干净坐标的二维协方差 Σ\_k。
3. 计算 z′ = Σ\_k^{1/2}·R(±2πk/N)·Σ\_k^{−1/2}·z，用它替换平面内的分量；平面之外的分量不变。

### A.5 探针与统计
- **状态探针**：在干净编码上训练多项逻辑回归，C 在 dev 上选。
- **逻辑回归基线**：特征先标准化，按 world 做 5 折交叉验证。
- **椭圆度与角度偏差**：见 P9b。

### A.6 合成自检（锁定前必须通过）
1. 在理想谐波码上，B1a 的状态分量为 0，B1c 能精确组合，B5 能精确组合。
2. LoReFT 的正交参数化在训练中保持正交（偏差 < 1e-4）。
3. 随机视野采样器给出的 S 分布是均匀的。
4. 逻辑回归基线能在合成特征上恢复已知规则。
5. decoder-only 接口：替换为同一个向量时，输出与不编辑时完全相同。
