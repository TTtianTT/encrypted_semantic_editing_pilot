## 1. 背景与问题

### 1.1 v4 留下的事实
1. **多尺度读出**（锁定）：
   - V1、V2a 在两个骨干上 8/8 符合 H-ms。
   - 读出一致率：拟合模型 0.945/0.937，等权模型 0.913/0.918，只用基频 0.555/0.526。
   - 拟合权重只比等权多约 0.03，所以读出本质上是"在槽位傅里叶子空间中取最近状态"。
2. **理想化预测失败，问题在动力学**（负责人的事后分析，P0 复核）：
   - 把同一个锁定的投票模型用在真实链的潜变量上（不解码），全部冻结条件 150 格中，类别预测对了 131 格（87%）；理想化派生只对了 92 格（61%）。
   - 逐 world 的整条链成败一致率：BART 0.933、T5Gemma 0.934。
   - 作为对照，"单步解码成功即判为整条链成功"的朴素预测只有 0.706/0.653；即使事先知道每格多数结果的参照，也只有 0.896/0.905。
   - hour 最典型：理想化预测 20 格错了 19 格，但读出一致率仍有 0.941/0.912。
3. **CE 捷径**（锁定，BART）：
   - 展开 CE 训练的编辑器在训练视野内几乎完美，过了视野一两步就崩，且不会复活。
   - compass 的视野正好是一整圈，第 5 步照样失败，说明潜变量记的是步数，不是状态。
   - 加了规范 L2 的 C3-U4 可以组合。
4. **秩分配**（探索性）：T5Gemma 上 FF-r 在 month r = 11、12，hour r = 14，compass8 r = 10 达到 1.0，而普通 RRR 为 0–0.61。BART 上只有部分改善。
5. **绑定**（锁定为 H-deep，但证据不足）：
   - 单头注意力编辑器的单步成功率为 0.90–0.99，R\_6 ≈ 0.02；注意力落在当前名字上。
   - 正对照上，注意力编辑器在 14–19 步后衰减。
   - 只用了单步 L2 训练。
6. **长程对称**：H-slot。T5Gemma 自然映射 month 的 0.869 只来自第 109 步之后的少量错误。
7. **谱**：s\_1 最小，13/13 成立。a\_1 最大在 T5 compass8 上不成立：k = N/2 的奇偶模式对应"正方向 vs 斜方向"，是打破平移对称的词形特征。

### 1.2 v4 设计上的教训
- V3 用了理想化预测。v3 已经显示理想化在交替路径上失败，本应改用模拟潜变量。
- V2b 用了通用阈值 0.25，而锁定模型自己就预测 hour 在 N/2 处约为 0；没有拿阈值去对照模型自己的预测做预检。
- R1 的可计分格子依赖理想化模型这一最弱的环节，结果 0 格。
- X 缺少多步规范监督的变体，而 U 已经表明这个变量是关键。

### 1.3 本轮问题

| 问题 | 竞争假设 | 决定性检验 |
| --- | --- | --- |
| Q14 能否不解码就预测可组合性 | **H-latent**：算子的潜空间动力学加上锁定的读出模型，就能预测每条链的成败，且明显优于"单步成功即可组合"的朴素判断。**H-decoder**：解码器还依赖槽位读出之外的东西，潜空间预测不比朴素判断好多少 | L：锁定前只编码、不解码，逐 world 预测；锁定后再解码检验 |
| Q14′ 能否用第 1 步识别指令捷径 | **H-detector**：第 1 步"潜变量读出 ≠ 解码输出"的比例高，就说明编辑器写的是指令，链必然不可组合 | L：比较 CE 系与 C3 系编辑器 |
| Q15 理想化预测为何失败 | **H-coupling**：冻结平面的偏差经算子耦合到其他平面；去掉耦合后，结果回到理想化预测。**H-readout**：去掉耦合后仍与理想化预测不符，问题在读出 | D：oracle 去耦冻结 |
| Q16 T5Gemma 的秩阈值是否来自秩分配 | **H-alloc** / **H-capacity**（在新数据上复现） | F：固定格子比较 FF-r 与 RRR-r |
| Q17 多步规范监督能否让跨 token 编辑器组合 bind3 | **H-train**：能。**H-deep**：仍不能 | B：展开 L2 训练的注意力编辑器 |
| Q18 机制在多模板语境中是否成立 | **H-general**：在未见过的句式上仍成立。**H-template**：只在训练句式上成立 | N：36 个句式，留出 1/3 测试 |
| Q11′ T5Gemma 上 CE 捷径是否复现 | **H-shortcut** / **H-state** | L4：T5Gemma 的 C1-U4 与 C3-U4 |

## 2. 执行规则

### 沿用 v4
- **提交方式**：所有 Python 计算都用 `sbatch` 提交，作业内用 `srun` 启动。登录节点只做 git、文件读写和 `squeue`/`sinfo`/`sacct`。入口脚本开头调用 `require_slurm()`。
- **GPU 并发**：
  - 任何时刻，本人名下正在使用的 GPU 不超过 2 张，其他项目的作业也计入。每个 GPU 作业只申请 `--gres=gpu:1`。
  - 只开两条串行通道：**A 通道跑 BART，B 通道跑 T5Gemma**。同一通道内的作业严格串行。
  - 通道首个作业提交前运行 `gpu_guard.sh`。依赖只写 `sbatch --parsable` 返回的真实 job ID。
  - 本人若另有 GPU 作业在跑，就只开一条通道，按 §12 末尾的单通道顺序执行。
- **模板**：复制 v4 的 `job_gpu.slurm`、`job_cpu.slurm`、`gpu_guard.sh`、`ledger.sh`、`lib4.py`（改名 `lib5.py` 后扩展）。作业名前缀为 `compmech4-`。T5Gemma 作业用 `--mem=96G`、`--cpus-per-task=8`。
- **分区**：先查 `sinfo`，默认用 `B300q`，避开 drain/down 节点。
- **预算**：GPU 分配时间上限 20 GPU 小时（`sacct` 记账，写入 `run_ledger.json`）。到 15 小时先报告，到 20 小时立即停止。预计 11–15 小时。
- **冻结**：
  - BART-base revision `aadd2ab…`；T5Gemma `google/t5gemma-2b-2b-ul2-it` revision `6a196a58…`（按 `model_manifest.json` 校验 SHA256），bf16。
  - 编辑器为 float32；seed 42、43、44；确定性方法不算作多个 seed。
- **提交**：每完成一个编号单元，提交一次并推送，提交信息为 `compmech4: <编号> <一句话结果>`。`local/` 不入库；超过 50 MB 的单个文件不入 git。
- **偏差**：一律写入 `DEVIATIONS.md`，注明时间、原因、影响，以及发生在锁定前还是锁定后。
- **锁定后**不得修改预测、阈值或判定规则；修改必须新建 `AMENDMENT_xx.md`，受影响的预测降为探索性。
- **其他标准步骤**：重建闸门（reencode ≥ 0.99）、合成自检、冒烟测试（只用 dev）、文本级去重（对仓库中全部实验的全部渲染文本）、区分力预检、world 级 cluster bootstrap。

### 新增
1. **confirm5 可以在锁定前编码，但锁定前不得解码。** L、D、N 的预测只用编码与算子动力学计算，逐 world 写入协议。`lock.py` 断言不存在任何 confirm5 的解码输出。
2. **凡是模型给出的预测，就直接以模型的逐格预测为准**，不再另设通用阈值。通用阈值只用于本身表述就是通用的假设，如 H-general、H-deep。若某格中模型自己的预测落在通用阈值的另一侧，该格在锁定时就排除并记录。
3. **确认性检验不得经过已知较弱的组件。** 本轮的预测不再使用理想化冻结。理想化预测只在 D 单元中作为被检验的对象出现。
4. **新训练的编辑器全部在锁定前训练完毕**（只用 train，准入只用 dev），这样 L 可以在锁定前算出它们的预测。
5. **新增的源特异文件**（句式、解析器）在锁定前定稿，锁定后不得修改。

### 6.2 锁定前的预测（`simulate.py`，不解码）
1. 在 confirm5 的编码上，对每个算子或编辑器、每条路径，按真实动力学逐步计算潜变量。
2. 用锁定的拟合投票模型读出每一步的状态，得到逐 world、逐步的预测状态，以及预测的整条链成败与格子类别（≥ 0.90 为可组合，≤ 0.20 为失败，其余为部分）。
3. 全部写入协议（逐 world 的文件以 SHA256 锁定）。

### 6.3 锁定后的测量
- 每步都解码，记录解码状态与成败。
- **朴素预测**：第 1 步解码成功就判整条链成功。
- **第 1 步分歧率 D**：可解析的 world 中，第 1 步"潜变量读出 ≠ 解码状态"的比例。

## 7. D：平面耦合（Q15，两个骨干，核心）

### 7.1 条件
- 域：BART 五个 V 域（weekday、month、hour、compass8、season）；T5Gemma 四个（weekday、month、hour、compass8）。
- 标准冻结 F\_S（与 L 共用）与 **oracle 去耦冻结 D\_S**（附录 A.3），S 取 {1}、¬1 与全部 {j}（j ≥ 2）。
- 路径：plus、minus、交替，各 2N 步。
- 理想化类别：v3/v4 已锁定的派生类别（不重算）。

### 7.2 预测

| 编号 | 格子 | H-coupling | H-readout | 判定 |
| --- | --- | --- | --- | --- |
| D1 | C = confirm5 上标准冻结的观测类别 ≠ 理想化类别的格子（锁定后按此规则确定） | D\_S 的类别 = 理想化类别，≥ 75% | D\_S 的类别 = 标准冻结的类别，≥ 75% | \|C\| < 6 时不可评 |
| D2 | hour，每个骨干的 D{j}（j = 2…6）单向 plus | ≥ 4/5 格 R\_2N ≥ 0.90 | ≤ 1/5 格 | 门槛：标准 F{j} 在同一骨干上至少 3/5 格不可组合，否则不可评 |

## 附录 A：定义

### A.1 潜空间预测器
1. 对算子或编辑器 T 与路径 op\_1…op\_K，令 h\_0 = E(x\_0)（confirm5 编码），h\_t = T\_{op\_t}(h\_{t−1})，与链式评测完全相同，但不解码。
2. 第 t 步的预测状态为 ŷ\_t = argmax\_y S(y; h\_{t,slot})，S 为锁定的拟合投票模型。
3. 预测的整条链成功，当且仅当所有 t ≤ 2N 都有 ŷ\_t = g\_t。

### A.2 第 1 步分歧率 D
在第 1 步解码可解析的 world 中，ŷ\_1 ≠ 解码状态的比例。只对训练过的编辑器计算。

### A.3 oracle 去耦冻结 D\_S
1. 第 t 步的输入为 h\_{t−1}。先把槽位上平面 S 的分量换成正确值：ĥ\_s = h\_{t−1,s} − P\_S h\_{t−1,s} + P\_S c\_w(g\_{t−1})。
2. 对替换后的潜变量施加算子：h″ = T(h\_{t−1}，其中槽位换为 ĥ\_s)。
3. 把输出槽位上平面 S 的分量设回冻结值：h\_{t,s} = h″\_s − P\_S h″\_s + P\_S h\_{t−1,s}。
4. 这样，其他平面的演化就像平面 S 是正确的，不受耦合影响；而读出看到的平面 S 仍停在起点。
5. 这是一种 oracle 诊断，用到了金标准状态，不是实用的编辑器。

### A.4 B 单元的编辑器与展开 L2
- **Tok-U**：Δ\_i = b + U V h\_i，秩 32。
- **Att1-U**：同 v4 的 Att-L2。
- **Att2-U**：两个头，每头 d\_a = 64，两个头的输出拼接后经 W\_o（d × 128，零初始化）。
- **展开 L2**：
  - 每次更新，等概率抽路径类型（plus^S、minus^S、交替），从 {1, 2, 3, 4} 中均匀抽 S，batch 16；
  - h\_s = T\_{op\_s}(h\_{s−1})；损失为 (1/S) Σ\_s 相对 L2(h\_s, E(x\_s))（定义同 v4）；
  - AdamW 1e-3，梯度裁剪 1；梯度穿过整条展开链。

### A.5 cluster bootstrap 与区分力预检
- 同 v4：以 world 为单位抽样 2000 次，种子 3101。
- 模型预测类检验，以模型的逐格预测为准。
- 通用阈值类检验，锁定前对照模型自己的预测：落在另一侧的格子排除并记录。

### A.6 多模板评测
- **成功**：输出与金标准文本在去掉首尾空白、并把连续空白合并为一个空格后完全一致（区分大小写）。
- **解码状态解析**：
  - 用句式生成正则表达式：除槽位外的部分按该 world 的取值转义填入，槽位为该域状态词的析取。
  - 匹配成功则取槽位中的词，否则记为不可解析。
  - 含干扰词的句式中，干扰词按该 world 的取值固定填入。

### A.7 合成自检（锁定前必须全部通过）
1. **去耦冻结**：在含已知平面间耦合的合成算子上，标准冻结会泄漏；去耦冻结下，其他平面与 oracle 完全一致（误差 < 1e-6）。
2. **潜空间预测器**：在读出已知的合成链上，与模拟解码器的一致率为 1.0。
3. **句式解析**：全部句式的金标准文本都能解析到正确状态；干扰词不被误认为槽位。
4. **Att2-U**：在 v4 的合成指针复制任务上，留出相对 L2 ≤ 0.05；Tok-U 仍 ≥ 0.5。
5. **展开 L2**：S = 1 时，损失与单步 L2 完全一致。
6. **D 与 bootstrap**：用手工构造的输入做单元测试。

## 附录 B：多模板句式的编写规则（weekday、month、hour 各 36 个）
