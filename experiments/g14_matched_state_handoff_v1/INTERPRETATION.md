# G14 结果解释与边界

1. **改变生产者确实改变了固定 G 接收者的正确性。** 在两路当前全文均为正确 today、mask 逐元素相同的所有 160 个世界上，F3 IID 的 G→G 为各 seed 160/160，而 R→G 为 76/160、4/160、22/160。来源差的三 seed 均值为 78.75pp，sample SD 23.42pp，共享世界配对 bootstrap 95% CI [75.21,82.08]pp。方向一致，幅度具有明显 seed 差异。OOD 来源差均值为 69.38pp，SD 5.96pp，CI [62.50,75.83]pp；旧路径本身在 OOD 也未全部成功。

2. **F3 新接收者不能可靠接收旧 G 的 today 编辑态；旧 G 只能接收一部分新状态。** F3 的 G→R、R→R 在每个 seed、每个 split 都是 0/160，因此固定 F3 接收者的来源差为零是“两路都失败”，不是正确互换。逐世界四种配对计数完整公开。每个 0/160 的 Wilson 95% CI 为 [0,2.34%]，160/160 为 [97.66%,100%]；退化 bootstrap 不能排除总体不确定性。

3. **现象也出现在 F2，并非只能由 F3 编辑态锚点监督解释。** F2 的 R→R 同样在所有 seed/split 为 0/160；但 IID G→R 为 86/160、0/160、129/160，R→G 为 37/160、60/160、0/160。F2/F3 共同匹配集合均为 160/160，直接比较没有分母错配。不能仅看两组 R→G 的平均值接近而忽略各 seed 方向和逐世界配对差异。

4. **自然输入和真实自由输出重编码恢复 IID 续步；本数据没有 mask 差异。** 所有 seed 的 G/F2/F3 自然 today→yesterday 都为 160/160，重编码两路真实当前输出后也如此。所有自然重构为正确全文，所有自然 mask 与源 mask 逐元素相同；C 上重编码 token IDs、mask、encoder memory 与自然控制完全相同。因而本次观察到的恢复不能归因于 mask 长度变化，也没有 IID 自然技能缺失这一解释。OOD 的自然技能存在边界：G 为 120/160、122/160、136/160，F3 为 157/160、149/160、160/160，F2 为 128/160、153/160、160/160；对应重编码结果完全相同。这些重复控制不是新增独立样本。

事前固定的案例 seed42/IID/g14_iid_0137 中，两路当前全文都是同一正确 today；G 接收两路都输出正确 yesterday，F3 接收两路都输出 two days ago。真实输出重编码后，两接收者均正确。这一世界符合“接收规则更新后在两种编辑态上失效”的有限行为描述；另一些世界改变生产者或接收者都足以破坏旧成功路径，不能唯一归因到一端。12 个案例均按事前 hash 顺序保留，未依据该模式选取。

错误分类保留解析未决。例如 F3 seed42/OOD 的 R→G 有 71/160 解析未决，不能将它们全称为确认日期错误、事实保持或“推进过头”。完整日期偏差、事实解析和错误类型见逐例工件与 CSV。

结果支持当前正确文本不足以保证这两个固定接收者下的后续编辑互换性，并定位到接收者更新与生产状态兼容性两方面的行为差异。G14 没有新训练，也没有同来源训练/IID 对照，不能据此判定普通样本过拟合；更不能证明语义丢失、所有可能编辑器都不可用、表示空间有内在缺陷或纯 latent 编辑不可能。最小剩余问题是解释已定位的 today 编辑态兼容性为何随接收规则与生产者变化；本轮不自动执行新训练、内部机制探针或长链扩展。
