# Limits of the controlled grammar and world specification

Core tasks use reversible explicit identities, legal transitions, fixed world
facts and one primary object. They do not test unrestricted natural language.
The parser accepts declared paraphrases and coordination; a reasonable expression
outside that finite grammar may remain unresolved. Such outputs are not automatically
labelled a proved anchor, participant or semantic error.

Time C is a discourse anchor, not a simulated physical clock. The planned,
completed or cancelled record is independently given and never inferred from
relative date. Fixed launch date is implicitly defined as E−2 days by the challenge
relation; it is a derived field, not a separately sampled event. The original
historical quote is an utterance record, without a factivity assumption, and its
date/words need not agree with E. The secondary position fixture instead gives
Q=E−3 and the fixed quotation "The OBJECT event is dated three days from now."
Both secondary orders share Q and words. No data or interpretation of original
predictions is silently replaced by the secondary fixture.

Person's third-pronoun challenge uses a synthetic naming convention: Alice,
Carol, Emma and Grace take she/her/herself, the other listed names take
he/him/himself. This is a dataset convention, not a claim about real people or
a test of independently supplied gender attributes. Explicit giver/recipient/owner
antecedents bind the sole third-person participant. Core text uses proper names
for third person and does not depend on this convention.

The extra reflexive event is defined as participantA keeping A's own key for A;
the primary transfer remains A→B with ownerC. When the primary object's type is
also key, the gold interpretation requires distinct key instances. The text does
not explicitly name those instances, and the evaluator does not establish object
instance identity. Reflexive participant binding results therefore cannot be
used to claim unique-instance ownership reasoning. This challenge is excluded
from core fitting/cycle admission; all its predictions remain in the report.

The primary role graph is one fixed A→B transfer with ownerC plus each declared
static challenge event/quotation. The secondary order fixtures change expression
position, not arbitrary graph topology. Plurals, collective reference, ambiguous
pronouns, observer translation and indirect/free-indirect quotation are unexecuted
extensions. Different incoming editor histories also have limited matched coverage:
one deterministic incoming direction per current state in the fixed-source matrix.
No claim generalizes these findings to every semantic operation or language model.
