# Post-core language-structure controls (frozen before this phase)

The original protocol evaluates natural single-step challenge editing but does not separately decode unedited challenge encodings. This secondary phase adds that missing generation control and tests continuations only for structures with basic dev competence. It is added after original BART test observations; it is explicitly a post-core protocol extension, not represented as part of the original preregistration. No training, model interface, parser, editor parameter, hyperparameter, seed or checkpoint changes are permitted.

Use the primary corrected spatial study for space and the original study for time/emotion/person. Eight one-GPU tasks, each model/domain task processes all three frozen seeds42/43/44. Unedited reconstruction is backbone-dependent and performed once per model/domain, on full dev and test expression/challenge templates (2–5, plus6person), deduplicated by world/state/template. Existing core reconstruction controls remain available separately. World splits, generator text and gold are unchanged.

For every seed whose core gate passed, evaluate its selected P on complete dev expression/challenge atomic pairs and gold-current-reencoded next-step pairs. A template is eligible for secondary continuation evaluation only if reconstruction≥.95, P natural atomic≥.85 with min state/sign cell≥.75, and gold-next≥.85/mincell≥.75. These thresholds are inherited from the original gate, not tuned to observed test performance. The chosen P remains the original core-dev-NLL checkpoint. Ineligible structures are retained as not_admitted_structure; no generation or scope failure is labelled latent composition failure on that basis.

For each eligible template, run all32test worlds and the same forward/reverse/inverse legal1–5step latent/decode-reencode/gold-reencode trajectories, for P and all available N/S/M checkpoints at both holdout partitions. No new supplement fitting. Pure latent never reencodes its prediction, and no method gets new operation information. Gold-reencode is only a current-text atomic competence control. Save per-example raw predictions, hashes/checkpoint index, per-step endpoint/conditional/full success and scope/preservation/parseability/controlled grammar. No additional source×state producer matrix is constructed for these structures; the original source-transfer matrix remains core and expression only.

Every output shard is atomic and immutable. Restart can only recover missing shards after terminated allocations, never rerun a low score or change gate thresholds. One array%2 starts after every existing project array; every task uses sbatch+srun and inherits CUDA_VISIBLE_DEVICES. One GPU/task, B300q,4CPU,64G,2h. All consumption is included in the original project48GPUh cap and two-card concurrency ledger. The final CPU report waits for this phase and includes all gate failures, unexecuted paths and technical failures.
