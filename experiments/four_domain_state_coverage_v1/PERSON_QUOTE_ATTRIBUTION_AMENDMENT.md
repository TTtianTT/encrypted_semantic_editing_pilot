# Post hoc outer quotation attribution interpretation

This audit was introduced after person diagnostic GPU outputs, when fixed-case
inspection found a conservative false negative. In a current context with
Speaker Carol and Listener Henry, "I said to Henry" outside a historical quotation
refers to Carol and can preserve the same historical speaker identity. Proper
name literal matching is too restrictive. The historical quotation itself remains
fixed word for word; its inner I/you bind to its own historical participants.

The adapter reads unique, actual emitted Speaker/Listener headers outside the
single direct quotation. It resolves subject I to the actual Speaker, subject you
to the actual Listener, object me to the actual Speaker and object you to the
actual Listener, only in the reporting clause immediately before that quotation.
It does not use gold names to substitute an actor, repair a wrong header, infer
unbound third-person pronouns or repair subject/object case. Quote words never
change. Wrong target context, wrong historical receiver, changed historical words
and non-target fact loss still fail independent comparison. CPU positive/negative
controls separately check all ordered triples of the eight identity names.

All available person predictions in both models/three seeds/conditions/formal
and diagnostic stages receive the same post hoc scorer. Raw predictions, raw
scores, admission, cohort membership, checkpoints and GPU behavior are retained.
Natural core/source matrices do not contain historical attributions, so this
amendment does not reselect or change the primary N/S/M fixed-source comparisons.
No active worker or decode–reencode input is modified, and no new GPU inference
or training is introduced. Full groups, changes and fixed first review cases are
published separately; post hoc counts do not masquerade as the initial scoring.
