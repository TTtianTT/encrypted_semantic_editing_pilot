# Identity readout extension (frozen before fitting)

The initial masked-mean probes distinguish current-state index, target role slot and object. A role slot does not identify an arbitrary named participant. This small post-behavior extension reads named identities from the already frozen source representations. It cannot change model checkpoints, thresholds, datasets or behavioral conclusions.

For every admitted model/domain/seed in both study directories, use only local/formal/<run>/probe/P_train.pt (24 original train worlds, every current state) for fitting and sources/P_test_t0.pt, Q_test_t0.pt and U_test_t0.pt for independent test worlds. Verify all cache SHA against their manifests. No source refresh and no encoder/decoder execution. Fit separately for current-state, target-object, target-subject identity and anchor-owner identity; person also listener/agent/patient/owner identity; emotion also non-target evaluator identity. Targets are defined by the existing structured world, not inferred from emitted predictions. Participant classes are the fixed eight NAMES and object classes the fixed eight OBJECTS.

Anchor owner is the main observer for space and current speaker for person. Emotion has no temporal/spatial anchor; its focus evaluator is the edit-scope owner. Time core external-anchor ownership is constant and not independently identifiable: report this limitation without fitting a meaningless classifier. No causal claim about selecting between external anchor and historical direct quote is possible from the available core-only caches. That distinction remains a behavioral challenge measurement, not a probe discovery.

Mean-pool over nonpadding tokens, center/scale by train features (std floor.01), linear readout, AdamW lr.01/weight decay.01, exactly100full-batch updates, fixed seed20261002. No validation selection or accuracy-driven changes. Fit on P only and test cross P/Q/U. No class may be silently remapped when absent from fit; record train-class coverage and chance class frequency. Report overall and current-text-correct accuracy, plus accuracy among semantically correct current states whose P/S/M receiver next step fails. Repeated operation rows are not independent and do not alter fitting.

All GPU probe work runs in sbatch/srun tasks under the same project lock, ledger and afterany dependencies on all existing arrays. One array%2, one GPU/task. Failed or not-admitted source tasks get explicit skipped status. No subspace intervention is performed. Readability is evidence for decodability by this probe, not evidence the editor uses a variable.
