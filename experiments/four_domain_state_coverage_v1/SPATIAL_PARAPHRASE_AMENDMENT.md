# Spatial first-person paraphrase scoring audit

Registered after observing formal predictions, before linguistic-control and position-diagnostic GPU evaluation. This is not the original preregistration. Original formal scoring code, thresholds, checkpoints, caches, candidate sets and scores remain unchanged.

The legacy parser accepts `I see the parcel on my left` but rejects the equally clear `I see the parcel to my left`. The first test-world/seed43 expression prediction in the relation-confirmation study demonstrates this false rejection. Therefore raw space-expression zero success cannot be interpreted as zero semantic ability. Other malformed or ambiguous expressions remain unresolved; in particular, `on my front`/`on my back` are not silently made correct.

The independent scoring adapter requires exactly one emitted `Observer: NAME.` header, recognizes only standalone unquoted `I see the OBJECT ... .` clauses, and converts actual ahead/behind or on/to-my/the-left/right wording into an equivalent relation clause. An optional `that is` relative clause is accepted. It preserves the emitted object, emitted observer, actual relation and every other span. It does not consult gold while normalizing. Quoted spans, viewpoint-prefixed clauses and unsupported language are not repaired. Observer/object/relation mistakes, fixed-observer/object mistakes and quantity contradictions remain rejected by independent guards.

Apply this scoring adapter uniformly to all existing spatial predictions as a separately named post hoc adjudication. Report raw and adjudicated success, false rejections, explicit contradictions and unresolved coverage. Keep original fixed source cohorts; do not replace a failed current representation or refresh caches. Any newly qualified expression-source comparison is a separately labeled post hoc cohort selected only from current outputs, before evaluating receiver continuation differences.

For the pending linguistic/position stages, freeze the same adapter before their GPU work and apply it to reconstruction, atomic, gold-current next step and all receiver trajectories equally. Only scoring receives equivalent wording; model input, decoded text, decode–reencode input, operation signal and hidden histories remain untouched. Preserve prior locks/code and record new hashes. No training, checkpoint selection, threshold or budget changes are allowed.
