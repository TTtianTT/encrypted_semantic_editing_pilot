## Scientific configuration

Four independent domains; each has two rank16 residual low-rank affine operators, `h + mask*(b+U(Vh))`, one per signed operation. Per operator33*d parameters:25,344 BART and76,032 T5Gemma, total50,688/152,064 per domain. Equal rank is not equal parameter budget. All backbone parameters frozen; model.eval; dropout off. BART float32; T5Gemma bfloat16 backbone and float32 editor, using the existing G5 convention. SDPA; no TF32. T5Gemma uses the official user chat template and fixed copy instruction. Input memory includes all valid wrapper/special tokens; padding is invariant. Greedy decoding, beam1, no sampling, no forced EOS, maximum160 new tokens. No source truncation. Source cap192 BART/256 T5Gemma; cap violations are technical failures and remain recorded.

Operation signal is plus/minus only. Time plus advances external anchor a day. Space plus rotates the named main observer clockwise. Emotion plus raises the evaluation of the evaluator/object named in the Focus header. Person plus rotates explicit speaker/listener through three identities. Headers are part of editable text, not a separately updated oracle. No method receives target text or gold state as operation input. Gold-reencode alone receives correct current text by definition as an atomic capability control; it receives no extra answers for the next step. Pure latent decoding is observation only.

States: time r=-3..3, emotion0..4, space facing0..3, person context0..2. Time fixes absolute event date/status; space coordinates/observer positions fixed; emotion has an artificial ordinal scale, no psychological distance claim; person event identities/ownership fixed. No saturating transitions; illegal chains omitted. See DATA_SPEC.md.

All variants of a content world share split. Each domain96train/24dev/32test worlds; train templates0/1, expression holdout2, structural challenge3/4/5. Content-identical core worlds are deduplicated before splits, even if unused dates/coordinates differ. Core template sharing is intentional IID, not expression generalization. All legal natural state transitions appear in atomic train. Edited continuation holdouts differ: time H=2 then−2, space H=1 then3, emotion H=1 then3, person H=1 then2. S current=0 (time/space/person),2 emotion. M covers time−1,0,1; space0,2; emotion0,2,4; person0 plus the one other nonheld-out state. Two partitions share atomic P but have independent supplement checkpoints, and are reported separately. Boundary-valid operation subsets are explicit.

## Training, selection, and gates

Engineering trial: seed42 only,160 atomic updates on train, full core dev reconstruction and atomic check; no test. It checks code/gradient/mask/serialization and measures time/memory. Formal hyperparameters freeze after this engineering-only stage; no test-based changes. Atomic P:600 updates, batch8 semantic examples, microbatch2 with accumulation4, AdamW lr0.001, no decay, norm clip1. Balanced round robin signed operation. Candidate every100updates; choose lowest full core-dev per-example token-mean NLL, earliest tie. All600updates execute. Independent U producer uses seed+10000 and the same rule, separate optimization from P; U is never used for supplement losses or selection. Q is P's fixed step300 checkpoint, an old seen-source control. Source cache and parameter SHA remain immutable. Neither U nor current receiver replaces the fixed source.

Every formal seed42/43/44 first establishes reconstruction≥95%, atomic≥85% macro with every signed-operation/current-state cell≥75%, and gold-current-reencode next atomic≥85% with cell≥75% on full dev. Failed combinations are reported and do not enter N/S/M. Test gate results remain a separate capability audit; test performance cannot change eligibility, seed, checkpoint or budgets. Each backbone×domain is present even if failed. Engineering failure is not a semantic failure.

N/S/M each200updates, start from identical selected P. Each update has4general natural examples +2focus examples +2old-source protection examples. S focus uses fixed P outputs at one current state. M uses equal total focus slots distributed among eligible states. S/M old protection uses fixed Q at S current. N uses natural encodings at exactly the corresponding current states instead of edited inputs (its focus follows M state coverage), maintaining8 endpoint labels/update. Same steps, labelled endpoints, natural protection and old protection slot count for S/M; count actual target tokens and source-generation coverage, never claim equal FLOPs. Per-example mean CE gives one equal-weight semantic supervision unit per endpoint, independent of target length. No current-model online refresh. All source inputs are retained and their decoded correctness reported; supplement losses use only correct source states, with deterministic cycling over surviving train-world slots and rejection counts. If any required state/operator has fewer than8 qualifying train worlds, that source condition is marked infeasible rather than silently substituted. N uses the corresponding original gold text.

Primary supplement checkpoint is final200, no favorable intermediate/test selection. Save resumable optimizer/RNG/latest every20updates, plus final hashes. No scientific hyperparameter retries. OOM halves microbatch and increases accumulation preserving batch8; numerical/device/parser fixes are logged and repeat only missing output shards. Timeout resumes latest under same configuration.
