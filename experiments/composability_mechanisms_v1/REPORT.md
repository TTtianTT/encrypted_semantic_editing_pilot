分支 `experiment/composability-mechanisms-v1`。协议锁定于提交 `e2fa258`（`protocol.json` SHA256 `ddabe9aa…`），锁定前没有任何 confirm2 或 S1b confirm 的编码、解码（`lock.py` 断言）。B4 按计划在锁定前用 train+dev 测得，不是前瞻性结果。可选部分 S4、S5 尚未执行，见 §7。

## 1. 结论

- **健全性闸门 G2-0 通过**：confirm2 上，自然映射 RRR-16 的单向 R\_2N 在 5 个域都是 1.000；C1 的 R\_2 在 15 个“域 × seed”组合上都是 0.000。v1 完全复现，自然映射的 RRR 拟合与 v1 逐位相同。
- **Q1（对称是否必要）：支持 H-slot**。10 个乱序循环/路径的 E\_iso 为自然映射的 1.7–76 倍，其 RRR-16 全部完美可组合：单向 R\_2N 都是 1.000，循环域走 10N 步（month 为 120 步）也是 1.000；R\_10N(自然) − R\_10N(σ\_max) 在 4 个循环域都是 0。**在单 token 槽位上，几何对称不是线性编辑可组合的必要条件。** 两项只用于核对机制的预测（A4、A5）未通过，“对称体现在算子正规性上”这一理论修正没有得到支持（§3）。
- **Q3（秩阈值）：支持 H-rank，R1、R2 通过**。可组合所需的秩正好是 N − 1：weekday 6、month 11、compass 3；egoside 是 4，在允许的 ±1 之内。在阈值处从 0 跳到 1，而单步成功率在远低于阈值的秩上已经是 100%。机制很清楚：**链可组合，当且仅当算子单位模块里出现了基频谐波 k = 1**。在每个秩不足的设置中，只要在槽位上用 oracle 补上缺失的谐波分量，R\_2N 就从 0 恢复到 1.000。R3 未通过（乱序映射的单步成功率同样是 100%）。
- **Q4（C1 写入的是什么）：支持 H-instr**（M1–M3 符合 H-instr，M4 符合 H-approx，3:1）。C1 在不同源状态上写入几乎同一个向量（余弦中位数 0.986），与规范写入正交（0.003）；探针在编辑后状态上 100% 读出**源**状态。写入只在槽位上起作用，推力只在 0.75–1 倍的窄窗口内产生“下一状态”。
- **Q2（绑定）：不可判定**。BART 无法重建 S1b 模板 0 的规范状态（reencode 单步成功率只有 0.25–0.41，会把事实从句里的物体名改掉）。按锁定规则 B2 记为 H-bind，但 B1 也失败了（pron3 0.27，name3 0.36），说明失败来自重建天花板，而不是绑定。锁定前测得的槽位可预测性（B4）支持 H-bind：bind3 的 R² 为 0.447，pron3/name3 为 0.997/0.991。但这只是表示层面的证据。模板 3 的 reencode 为 1.000，修复路径明确，需要负责人新建 AMENDMENT（§7）。

**对论文主线的含义**（PLAN §12 第一行，绑定部分暂缺）：可组合性由“写入规范状态（不是 CE 推力）”和“秩覆盖全部 N − 1 个非平凡谐波”决定，与几何是否对称无关。论文主线可以写成“解码正确 ≠ 可组合：写入目标与谐波覆盖”；绑定这一条要等 S1b 修复后再定。

- 所有乱序映射的 dev 单步、confirm 单步与链式成功率都是 100%。

## 4. S2 秩定律（`figs/s2_rank.png`，`results/s2_modes.json`，`figs/s2_modes.png`）

| 域（自然映射） | N − 1 | 单向 R\_2N 随秩变化 | 单位模块中出现的谐波 |
| --- | --- | --- | --- |
| weekday | 6 | r = 4、5：0；r ≥ 6：1 | r = 4、5：{0, 2, 3}；r ≥ 6：{0, 1, 2, 3} |
| month | 11 | r = 8、9、10：0；r ≥ 11：1 | r = 8：{0, 2, 6}；r = 9、10：{0, 2, 4, 5, 6}；r ≥ 11：全部 |
| compass | 3 | r = 2：0；r ≥ 3：1 | r = 2：{0, 2}；r ≥ 3：{0, 1, 2} |
| egoside | 3 | r = 2、3：0；r = 4：1 | r = 2、3：{0, 2}；r = 4：{0, 1, 2} |
| daysago（开链） | — | r = 6、7、8：0；r ≥ 10：1 | 只有 {0} |

- **谐波覆盖决定可组合性**：每个失败的秩都缺基频 k = 1，而且只缺它（以及部分高频）。Oracle 只在槽位上补回缺失谐波，R\_2N 在 weekday r4、r5，month r8、r9、r10，compass r2，egoside r2 上全部从 0 恢复到 1.000（探索性）。
- 单步不需要基频：秩不足时单步成功率仍是 100%（compass、egoside 的 r = 2 为 0.76/0.83），所以“解码正确”与“可组合”在秩轴上明确分离。
- R3：σ\_max 的单步成功率同样是 100%，未通过。weekday σ\_max 的 r\* 为 6（与自然映射相同）；month σ\_max 的 r\* 为 16，在 r = 11–14 时单位模块缺 k = 1，R\_2N 为 0.21–0.31。因此“覆盖全部谐波”是共同的判据，但乱序映射下 RRR 的秩分配与谐波的对应关系不同。
- R5（daysago，探索性）：r = 7、8 时全部失败都发生在走进边界的那一步（8→9、3→2）；r = 6 时失败在中段（5→6）。
- 异常（探索性）：month 自然映射 r = 12 的交替链在第 14 步之后逐渐失败（非目标事实被破坏，例如“5 5 copies”），而 r = 11、14 都是 1.000。这是上下文 token 的误差在长交替链中累积，与槽位谐波无关。

解读：C1 主要在槽位上写一个与源状态几乎无关的“+1 指令”（egoside 有部分作用在槽位之外），编辑后的状态在表示上仍是源状态（探针 100% 读出源），解码器把“源状态 + 指令”执行成下一状态。指令只在一个窄幅度窗口内有效，而且不能叠加（两倍推力不会得到 +2），这就是 C1 第二步必然失败的原因。M4 的域差异说明，循环较长的 weekday/month 中“指令”基本可以在源之间互换；而在 Z4/daysago 中，写入虽然方向近乎相同，残余的源特异成分仍然必要。
