# 基线与执行审计

工作区起始干净、无相关运行作业、无适用AGENTS.md。已从公开bc5087483b5c3d2476d615d8e9452b0f54bd289c新建独立分支experiment/joint-reference-editor-v1。阅读并复用其encoder输出adapter、评分器、renderer、实际模型/环境manifest和G1 checkpoint；旧目录保持只读，完整旧资产hash另存。

基线的两种组合路径原先不总是同一个源视图，而且人称算子的训练支持仅±2。不能直接用旧报告中两条路径的百分比作本轮配对比较。本轮对每世界先取两路径共同合法且有实际源条件支持的视图，统一源、联合目标和分母；需要排除初始offset=-2，因为时间先行后的P_13输入offset=-3不在旧人称训练支持内。completed同时遵守view_date≥record_date。支持计数定义见task.py和data/old_support_counts.csv。

本轮480/80个train/dev世界保持旧事实与模板划分。联合训练枚举1600个合法视图，但按世界均衡采样9600次（每世界20次）；完整联合dev有266视图。新确认世界与全部旧实验完整事实键去重，固定每世界一个共同合法视图。模板OOD仍是原4个句法家族，词汇共享，不是自然文本或新词泛化。旧模板奇偶和否定相关等生成规律保持，不另外修订任务。

复用旧B包装calibration的400个源/联合目标输出，按本轮frame重评均通过。GPU预检32条G1旧路径逐字复现，包括完整中间文本；它们仅用于兼容性检查，不作为新共同域成绩。Joint16/32真实batch均验证零残差/直通生成一致、encoder确定性、活动编辑器与H梯度有限非零、骨干冻结且无梯度、非零残差下padding不变；低秩V首步梯度0符合U初始化0。无预检optimizer更新。

Joint16/32各自seed42初始化，不互相续训，也不加载旧任务编辑器。优化器仅含新编辑器参数，decoder允许梯度传回H；每microbatch的CE有效token总和除以整个16样本batch的token总数，再统一一次step。G1已有总监督9600样本分配给四个算子；本轮每组9600个样本全部直接监督联合任务，不能称等任务监督或等算力。

折叠是原G1两个仿射算子的代数展开，rank≤32、单偏置，无训练、无gold或规则纠正。数值与输出一致性以实测为准。它用于区分直接重新训练联合映射与仅把旧顺序函数改写成一次调用，不是第三个新训练组。

GPU沿用B300q（当前集群无L40S/A100分区），每作业单卡，经sbatch+srun；累计上限7200分配秒、并发最多2。预检作业1750为69 GPU秒，训练前保守训练估计约1953秒，预留评估约286秒；两训练作业各最多1800秒、评估最多1800秒，仍低于总预算。实际账本包含加载、开发和所有作业，不按父/step重复累计。基础模型在/dataset1/zailong/models/reference-frame-cross-backbone/，本轮不再下载或升级环境。
