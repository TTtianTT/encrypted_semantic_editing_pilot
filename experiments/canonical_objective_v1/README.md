# Canonical objective controls

Exploratory follow-up to canonical-write reachability. Frozen BART encoder/decoder; two affine rank-16 editors. Historical 80 held-out worlds, 96 disjoint training worlds. No independent confirmation is claimed. No delegation or backbone updates.

Before any new GPU execution, run `checks_c.py`, then `prepare_c.py` to lock source code, inputs, paths, training budget and coefficients. Run GPU phases through the provided Slurm script and `srun` only, with `CANON_PHASE=pre_c`, then `train_c`, `eval_c`, `mechanism_c`. Run CPU `summarize_c.py`, then `audit_c.py` after all phases. The pre-C phase has zero neural updates and must finish before training begins.

Every group/seed receives 600 updates of 8 examples (4 microbatches of 2), AdamW lr .001, no weight decay, gradient clipping 1. C1–C4 sample identical aligned batches for a given seed; C5 uses all legal transitions. Groups use the same random editor initializer, except C4 which balances the exact RRR factors without changing their affine map. Frozen model remains in eval mode throughout; teacher gradients and all backbone gradients are disabled. C2/C3 divide masked token MSE by per-operator train mean ideal-write energy. C3 L2 and C5 KL weights are fixed to 1. No tuning or checkpoint selection on historical evaluation worlds. C4 evaluates eight predeclared checkpoints; other groups evaluate the final checkpoint.

Closure repeats cycles returning to their start: two steps from 0, four steps from +1/-1; every step is decoded and compared against gold canonical state. Dose interpolates the actual CE and RRR maps on the same current state at every step; its effective rank may be 32. Dedicated canonical-source single edits test all aligned transitions for every dose. Likelihood overshoot uses the same gold decoder labels for edited and canonical states and masks padding.

Final-model single edits cover all legal transitions and explicitly retain whether a mask is aligned. R1–R5 cover the two original paths and two aligned paths, templates 0 and 3. S-coordinate metrics use all three frozen train-fitted S bases. PCA of each new editor's residual is fitted exclusively on aligned training transitions; angles are reported with absolute energy, centered energy, top-four fraction and eigengap. Fixed-S injection uses the corresponding historical CE source-0 residual for comparability; conditional sensitivity reports eligibility, current retention and next failure denominators.

Checkpoints and local caches are ignored by Git. Published tables retain actual outputs and scores. Atomic shard completion permits evaluation resume. Training checkpoints retain optimizer, random states and full history for exact update resume. Final five-seed confirmation on new worlds is deferred until a method and protocol are selected.
