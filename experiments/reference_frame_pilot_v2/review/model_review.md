# 模型复核，不是人工真值

主执行模型逐条读了27个固定导出候选：G0/G1/G2各8条打乱后的唯一未决输出，共24条；另有本批全部3条已解析非日期事实错误。具体判断在model_review_results.jsonl，原始上下文在model_review_candidates.jsonl。

这24个未决候选均包含明显词串退化、空输出或严重事实缺失，本次模型复核可确认这些样例失败；不等于确认全部未决都是语义错误。该便利样本不用于校正总体自动分数或估计准确率。

3条已解析非日期错误均出自G2：T_plus→T_minus把数量7改为4（日期正确）；T_plus³在IID和OOD各把数量2改为4，并把目标日期少移动一天。已解析G0/G1没有非日期槽位错误不代表全部事实保持，其未决输出有明确丢失事实现象。

所有组的自动plan_to_completed命中为0，但未决未穷尽语义审核，不能当作零风险证明。review/blind_review.csv的20世界、2175输出尚无人类填写。方法及路径映射保存在private_mapping.json，组织盲审时不要分发映射。
