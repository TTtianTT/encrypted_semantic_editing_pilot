# DEVIATIONS（composability_mechanisms_v6，计划 v7 的 B 线）

全部条目均在锁定前，除非另行注明。

1. **2026-11-24，P4 在 GPU 上运行（B3；锁定前）**。
   - 原因：计划把 P 列为 CPU 单元。P4 要用 v6 锁定的代码重算潜变量，而载入 v6 训练的编辑器要经过骨干引擎（`backend.editors`）。
   - 做法：
     - P4 作为两个 GPU 作业运行：73137（BART）、73138（T5Gemma），各约 40 秒。
     - 脚本直接从 v6 目录导入 `lib6` 与 `cells6`，因此动力学与锁定时完全相同。
   - 结果：47 个格子、701,760 个（world，步，读出）逐一比较，不一致为 0。
   - P1–P3 仍在 CPU 上运行。

2. **2026-11-24，P 中重复格子的判定（第 0 节规则 10；锁定前）**。
   - 第一次运行（73134）按解码记录的哈希判定重复，报出 288 组。原因是不同的编辑器只要整条链都正确，解码记录就完全相同，这种判定不能区分"权重相同"与"结果都完美"。
   - 改用 v6 分析中按权重判定的重复名单（`identical_cells`，依据锁定模拟中连续的上下文漂移值），共 21 个格子。v1 C3 是计划 B6 点名的编辑器族，保留为代表，C3n600 与 month C3n300 s42 作为重复删去（73135、73136）。
   - v5 L 与 v6 M 没有已知的权重重复。

3. **2026-11-24，T1 的判据与命题表述（B4、A3；锁定前）**。T 单元的数值核对改动了两条命题的表述。
   - **命题 1**：
     - T1.1 第一次运行（73139）用"在最近状态读出下能组合的最小秩"作 r\*。N = 12 时它小于 N − 1：等幅为 9，振幅按 1/k 衰减为 7。原因是：被丢掉的平面在读出中权重小时，链仍然能组合，这属于命题 3 的范围。
     - 命题 1 说的是精确映射，因此改为"把每个 c(x) 精确映到 c(x+1)（最大误差 < 1e-8）的最小秩"。按此判据，9 个设置全部等于中心化码张成空间的维数。
     - 读出相关的最小秩另行报告。
   - **命题 2**：计划写的是"保留一步能量 s\_k = 4a\_k² sin²(πk/N) 最大的平面"。
     - 按每个平面的能量排序，与降秩回归实际保留的平面在 58 个秩中吻合 49 个；按每个维度的能量排序（二维平面除以 2，Nyquist 平面除以 1），58 个全部吻合。
     - 差别全部来自一维的 Nyquist 平面。命题 2 应改为按每个维度的能量。
   - **单位**：数据文件中的 s\_k 是一步变化的均方根，等于 2a\_k sin(πk/N)，计划中的能量是它的平方，两者排序相同。
   - **命题 3 的平局**：闭式罚分与向量计算按"取到最小罚分的任一状态"比较，因为随机配置中有 4/300 个精确平局。
   - **T2(a)**：真实算子的逐平面误差在 ε ≤ 0.5 判据下几乎没有平面算作"保留"，所以该比较没有信息。另行报告"误差最大的平面是否就是预测最先丢掉的平面"。
