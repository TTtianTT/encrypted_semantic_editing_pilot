## 1. 结论

1. **Q20（预测器为什么高估）：两类案例的机制不同。**
   - **训练不足的状态监督编辑器（R2 = H-inspan）**：
     - 把槽位在平面内的位置放到位、保留离流形分量（PUSH），就能恢复 0.98 [0.97, 0.99] 的解码；
     - 只去掉离流形分量（PROJ）恢复 0.26，只修上下文（CTX）恢复 0.20。
     - 即编辑器写入不足：槽位读出已经翻到目标，解码器还没有翻过去。
     - 五个编辑器族中有四个各自也是 H-inspan，v1 C3 为混合。
     - 在新 seed 的复现（R4）中，PUSH 0.95、PROJ 0.28，但 CTX 达到 0.53，超过 0.40 的门槛，判为混合，所以按规则 R2 是"不稳定"。
   - **T5Gemma 未见句式的交替链（R1 = 混合）**：PROJ 恢复 0.64，PUSH 恢复 0.45，都没有到 0.70。R4 在新的 84 个案例上给出同样的判定（PROJ 0.67、PUSH 0.45），所以"混合"本身是稳定的。
   - **R3 差一点不成立**：CTX 修复后，对照步仍成功的比例为 0.968，门槛 0.97。PROJ 与 PUSH 的对照分别为 0.976 与 0.990，成立。
   - **R0 在所有族都成立**：SNAP 或 SNAP+CTX 恢复率 ≥ 0.99。
2. **Q21（能否不解码就修正高估）：H-nofix（探索性）。**
   - 锁定前的 dev 标定中，余量与离流形检查的网格里，没有任何阈值能提高一致率。U 因此退化为只看槽位，U1、U2 按预检降为探索性（DEVIATIONS #6）。
   - 确认集上的结果相同：U 与只看槽位的差为 0。
   - 不论哪一族，"预测会失败"的精确率都是 0.92–0.97。
3. **Q22（未见句式上交替路径为何变弱）：只有 A1 成立。**
   - **A1 成立**：交替链在 t = 2N 时的离流形程度，是单向链的 4.5–58 倍；单向链的 ρ 到 t = N 时反而下降。4/4 个组合成立。
   - **A2 不成立**：留出句式上干净输入的一阶误差，一圈和比为 0.26–0.66，交替对比为 0.22–0.56，4 个组合都不满足。训练句式的 dev 上一圈和比只有 0.08–0.14（探索性）。即一阶抵消只在训练句式上近似成立。
   - **A3 不成立**：把 P⁻¹ 当 minus 算子，单向 minus 的 R\_2N 在 4 个组合上都是 0。精确的逆在槽位上放大了离流形误差。
   - **A3b 成立**，但这一点由构造决定。
   - 按 B12，命题 4 只作为未经确认的解释，§8 只报告 A1 的现象。
4. **Q23（绑定）：30 步可以，100 步不行；视野对齐的 oracle 也闭合不了。**
   - **K5 = H-slow-decay**：Att2L-U8 的 R\_100 在全部 8 个 seed 上都只有 0–0.06。
   - **K6 = 混合**：新 seed 45–49 的 R\_30 为 0.08 / 0.28 / 0.58 / 1.00 / 0.98；v6 的 seed 42–44 为 1.00 / 0.98 / 0.99。v6 报告的闭合只在部分 seed 上复现。
   - **K7 = H-unrepresentable**：视野对齐的 OR-U8，R\_30 中位数为 0.04。
   - **K8（探索性）**：删去第 2 层后，8 个 seed 都是 0，(a)、(b) 两种消融也都是 0。
   - **K9**：bind3fix 上 8/8 个 seed ≥ 0.95；name3 上只有 5/8。
   - **机制（探索性）**：第 1 层在槽位上几乎全部注意"下一个名字"（0.89–1.00），第 2 层几乎不看名字位置。查找由第 1 层完成。
5. **G7-0 通过。**

**对论文主线的含义**：
- 只看槽位的预测器保留。高估的原因按族分开写：训练不足的编辑器写入不足（PUSH 可修复）；未见句式的交替链，单一的修复方向解释不了。
- §8 的"一圈抵消"降为未经确认的解释，只报告 A1 的现象。
- §9 绑定改写为：两层编辑器在部分 seed 上能组合 30 步，100 步全部衰减；对 seed 敏感；视野对齐的 oracle 也做不到，这与"表示不足"一致。

## 4. 各单元

### 4.1 R：修复实验
- **方法**：在案例那一步的潜变量上做一次修复，然后解码一次（附录 A.5）。案例来自锁定前冻结的清单（R-A、R-B），R4 的案例在锁定后从本轮的 U 链中抽取。

- **解读**：
  - 在训练不足的编辑器上，把槽位推到正确状态的平面内位置就够了（PUSH），离流形分量可以保留。上下文的作用在不同编辑器之间不一致：v1 C3 与新 seed 中 CTX 能修复约一半。
  - 在 T5Gemma 未见句式的交替链上，两种方向各修复一部分。
  - BART 的 R-A（次）则是 PUSH 0.98，与 R-B 相同。

### 4.2 U：带余量与离流形检查的预测器
- **标定结果**：网格内没有能改善 dev 一致率的阈值（DEVIATIONS #6）。确认集上，U 与只看槽位的结果逐 world 相同。
- **只看槽位的一致率**：F1 0.911，F1s 0.829，F2 0.808，F3 0.902，NI BART 0.975，NI T5Gemma 0.947。
- **类别准确率**：F2 只有 0.63，T5Gemma 未见句式上高估明显，与 v6 相同。

### 4.3 A：交替路径的机制
- **A1**：交替链的离流形程度在 2N 步时远大于单向链（4.5–58 倍），单向链的 ρ 到 t = N 时下降（比值 0.31–0.71）。现象与命题 4 的预期方向一致。
- **A2**：只在训练句式的 dev 上近似成立（一圈和比 0.08–0.14），留出句式上不成立（0.26–0.66）。交替对比在两种句式上都低于 0.50。即误差并不是"单向抵消、交替成对累积"这一简单的一阶结构。
- **A3**：用 P⁻¹ 当 minus，单向链从第一步起就失败（R\_2N = 0）。精确的逆不是可用的 minus 算子：v6 的 minus 算子是单独拟合的，它的离流形误差比逆算子小。
