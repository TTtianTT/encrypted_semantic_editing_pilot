## 5. 解读要点

### 5.1 为什么 (a) 失败

时间域的 7 个状态混合了 1、3、4 个 token 的短语，均值池化后形成长度簇，plus 跨簇的两步（+2→+1、−1→−2）把等距性打断。置换零分布中有许多“簇内游走”的映射，比真实 plus 更接近等距。这是对 ESEP 现有时间域的如实刻画：现有时间域的编辑本来就只在 {+1, 0, −1} 这段对齐区间内可组合，而这一段的几何确实近似等距（E\_iso = 0.005，小于 person 的 0.023）。

### 5.2 为什么 (c3) 失败，以及 ISO 指标的局限

C3 与 RRR 在 A\_Q 里都有接近 0 的奇异值（σ\_min 为 0.002–0.03），即把部分方向压扁，像投影一样吸附到规范状态上。这会推高 ISO，同时降低 e\_inv。ISO 衡量的是“全 Q 子空间上的正交性”，而好的编辑器在属性子空间上做旋转，在其余方向上做投影，并不追求全局正交。所以 (c3) 的预设方向与 (c1)、(c2) 相互矛盾，ISO 不适合作为“可组合性”的代理指标。这是对指标的事后观察，不改变本轮判定。
