# 修订 01：G0 判定规则（数据驱动）

- 日期：2026-11-22（E0 全部结果提交并推送之后，见提交 `e608520`、`b2b92f1`）
- 授权：项目负责人在看到 E0 与 G0 结果后书面指示：“G0(a) 改用 G1a，去掉 ISO 条款，继续 E1 和 E2”。
- 性质：**数据驱动的修订**。修订者已看到 E0.1–E0.3 的全部数值（REPORT.md §2、§5），E0 与 E2 仍是探索性结果。E1 的确认集预测（P1–P7）仍在看到任何 E1 编辑结果之前，由 E1.3 锁定；E1 的前瞻性不受本修订影响。

## 变更

| 项目 | 原规则 | 修订后 |
| --- | --- | --- |
| G0(a) 几何 | time 7 状态的 E\_iso、Toeplitz R² 对零分布，以及 time 片段 < person | **移除**。几何闸门改由 E1.2 的 G1a 承担：weekday、month（单 token、无长度扭结）中至少一个的 E\_iso 低于其置换零分布的 5% 分位。G1a 不通过则不做 E1 编辑评测（原计划已有此规则）。 |
| G0(c) 群律 | (c1) 每个 seed e\_inv(C3) < e\_inv(C1)；(c2) e\_inv(RRR-16) < 所有 C1；(c3) ≥4/5 个 seed ISO(C3) < ISO(C1) | **去掉 (c3)**，(c) = (c1) 且 (c2)。ISO 仍作为描述性指标报告（E0.2、E1.5 代数诊断），不参与任何判定。 |
| G0 判定 | (a) 且 ((b) 或 (c)) | **(b) 或 (c)** 成立即进入 E1.0–E1.2 与 E2；E1.3–E1.6 再受 G1a 约束。 |

## 理由

1. time 的 7 个状态是 1、3、4 个 token 的短语。均值池化后，几何主要由长度簇决定（REPORT.md §5.1），所以 G0(a) 测的是表面形式，而不是日期顺序的对称性。同为 4 状态、单 token 的 space 模板 1 几乎是完美的 Z4（E\_iso = 0.004，R² = 0.98）。E1 的循环域都是单 token，不存在这一混淆，所以把几何检验放到 G1a。
2. C3 与 RRR 在 A\_Q 中有接近 0 的奇异值（吸附到规范状态的投影型方向），这会提高 ISO，同时降低 e\_inv（REPORT.md §5.2）。(c3) 的方向与 (c1)、(c2) 相互矛盾，因此不作为判定条件。

## 不变的部分

E1.0–E1.6、E2 的设计、阈值与统计约定，P1–P7 的定义，预算（10 GPU 小时），Slurm 规则，seed，以及所有停止规则均不变。原 `results/g0_decision.json` 保持不变；修订后的判定另写入 `results/g0_amended_decision.json`。
