# 结构化自动检查 + 模型复核（没有真人真值）

主模型逐条读了 model_review_candidates.jsonl 的36个候选：两个方法各12条随机打乱后的唯一未决输出，以及先出现的12条已解析非日期错误。范围是便利抽查，不得估计全体输出准确率。31条在本次模型复核中可确认失败，5条方向/角色作用域不完整而不能确认成功。所有主表自动分数保持原样，没有扩大parser覆盖重算测试。

具体见model_review_results.jsonl。时间连续与往返的纯表示链出现大量不可理解日期词串、标题/记录日期和事件槽位丢失；这组观察支持实际生成退化，不仅是parser匹配问题。也有正常句式漏掉所有格后动作主体未定的情况，仍保留不确定。

已解析的非日期错误抽查确认Shift会把作者角色替换成接收者、改数量或丢取消标记；未把这些错误包装为仅风格变化。LowRank16已解析输出未检测到非日期槽位错误，不代表其全部输出保持事实，因为其未决链输出中有严重信息丢失。

额外读了初始前8条去重未决输出（非概率样本），发现Shift加入住院断言、生成daughter、删除动作报告等现象；不用于总体分数。整个实验自动plan_to_completed探测为0，但未决输出未被穷尽语义审阅，因此不声称全部失败输出的完成断言风险为零。
