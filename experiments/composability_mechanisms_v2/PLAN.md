## 1. 这一轮要回答什么

### 1.1 v2 留下的事实与缺口

1. **对称不是必要条件。** 10 个乱序映射的 RRR-16 全部可组合。v2 计划背景中“对称体现为算子正规性”的修正没有得到支持（A4、A5 未通过），本轮不再使用。
2. **秩阈值 r\* = N − 1，每个失败的秩都缺 k = 1。** 但有一个混淆：在 v2 的全部数据里，k = 1 总是最后进入 RRR 单位模块的谐波（month 中与 k = 3 同在 r = 11 进入），“k = 1 存在”与“全部谐波都存在”完全重合。oracle 修补也是一次补回全部缺失谐波。所以“基频是关键”和“必须覆盖全部谐波”还没有分开。
3. **逐步正确率呈周期性“复活”**（探索性：负责人用 v2 分片补算，P0-X1 负责复核）。秩不足的单向链出错之后，会在 t ≈ N、2N 附近重新答对：
   - weekday r = 4：A\_t = 1.00, 0.68, 0, 0, 0.56, **1.00, 1.00, 1.00**, 0.34, 0, 0, 0.12, **1.00, 1.00**。t = 3、4 时，解码器分别在 113/160 和 143/160 个 world 上输出**起点**状态。
   - month r = 8：A\_6 = 0，160/160 个 world 输出起点月份；A\_12 = 1.00，A\_24 = 0.93。第一圈中，答错时输出的是“与目标模 6 同余、离起点最近”的月份。例如 t = 7 时 138/160；t = 9 时两个候选与起点等距，输出比例为 56 : 55。
   - 交替链在同样的秩下大多不坏：weekday r = 5 与 month r = 10 的交替 R\_2N 为 1.00，month r = 9 为 0.99；weekday r = 4 撑过 7 步，month r = 8 撑过 13 步，egoside r = 2、3 走完 8 步。例外是 compass r = 2，交替第 2 步就失败。
4. **对 3 的待检验解读：**
   - 秩不足时，RRR 不更新的谐波平面被“冻结”在起点。
   - 解码器按各平面加权“投票”读出状态。weekday 中基频的票几乎压过其余平面；month 中 k = 2 平面的票也很重，所以输出是“k = 2 给出的模 6 余数 + 冻结基频挑出的最近别名”。
   - 交替链离起点最多一步，冻结平面从不造成大冲突，所以不坏。
   - 若此解读成立，“单步对、连续错”就可以由解码器的读出权重定量预测；最小可组合秩也由读出权重决定，而不一定是 N − 1。
5. **C1 写的是“+1 指令”**（M1–M3）。M4 的域差异仍无解释：weekday/month 的写入可以移植，Z4/daysago 不行。
6. **Q2 不可判定。** v2 计划的审计没有重建闸门，这是计划本身的缺陷。
7. **两处未解释的异常：**
   - month r = 12 的交替链在第 14 步之后失败，而 r = 11、14 都不失败。
   - month σ\_max 的 R\_2N 随秩不单调：r = 9、10 为 0.71–0.72，r = 11–14 为 0.21–0.31，r = 16 为 1.00。

### 1.2 本轮问题

| 问题 | 竞争假设 | 决定性实验 |
| --- | --- | --- |
| Q5 秩不足时为什么单步对、连续错？可组合需要保住哪些谐波？ | **H-drift**：离流形的状态整体漂移，与方向无关。**冻结平面**：未更新的平面停在起点，错误只随净位移增长。在冻结平面成立的前提下，再比较三种读出：**H-fund** 解码器只看基频；**H-complete** 任何平面被冻结都会出错；**H-vote** 解码器按平面加权投票，权重可在 dev 上标定，并能定量预测每一步解码出的状态 | H：在可组合的 RRR-16 上冻结指定平面；只改指定平面的槽位编辑器。预测由锁定前的 dev 标定算出 |

## 6. H：解码器怎样读出状态（Q5，BART，核心）

### 6.1 操作（定义见附录 A.3）
记 T 为 v2 拟合的 RRR-16（自然映射），P\_k 为槽位上的谐波平面，B\_k 为其正交基（附录 A.1）。

- **冻结手术 F\_S**：每一步先算 h′ = T(h)，再在槽位上令 h′\_s ← h′\_s − B\_S B\_Sᵀ (h′\_s − h\_s)。也就是说，平面集合 S 内不更新，其他位置照常。plus 与 minus 编辑器做同样处理。记 F\_¬1 为冻结除基频外的全部平面。
- **平面编辑器 E\_K**（只改槽位）：在 train 上对 K 内各平面的坐标联合拟合 z′ = A\_K z + c\_K（最小二乘）。编辑为 h\_s ← h\_s + B\_K (A\_K z + c\_K − z)，其余位置不动。plus 与 minus 分别拟合。E\_all 用全部平面（维数 N − 1）。
- **R16-slot**：RRR-16 只作用于槽位（参照，探索性）。
- **RRR-r**：v2 的 RRR，作用于所有位置。r = dim(K\*)，没有现成拟合就补拟合。

### 6.2 标定与投票模型（锁定前，只用 dev）
1. **替换探针**：对 dev 的每个 world w、状态 x、平面 k、位移 m ∈ {1, …, N − 1}，构造两种输入并解码，解析出状态或记为“不可解析”：
   - 单平面型：槽位 = c\_w(x) + P\_k (c\_w(x + m) − c\_w(x))，其余位置 = E\_w(x)；
   - 补集型：槽位 = c\_w(x) + P\_¬k (c\_w(x + m) − c\_w(x))，其余位置 = E\_w(x)。
2. **投票模型**（附录 A.2）：P(y | h) ∝ exp(−Σ\_k λ\_k ‖B\_kᵀ(h\_s − c\_w(y))‖²)，λ\_k ≥ 0。用可解析的探针结果做最大似然拟合。另拟合两个对照模型：等权（所有 λ\_k 相同），以及只用基频（只有 λ\_1）。
3. **派生预测**：对 §6.3 中的每个条件，用理想化槽位（转动的平面在当前目标，冻结的平面在起点；附录 A.2）在 dev world 上算模型预测的 R̂\_2N（plus、minus、交替各一个），并归为“可组合”（≥ 0.90）、“失败”（≤ 0.20）或“部分”。
4. **K\***：在全部非空平面子集 K 中，选理想化 E\_K 的三条路径 R̂\_2N 都 ≥ 0.95、且维数最小的一个。并列时取三条路径最小 R̂ 较大者，再并列按字典序。若只有全部平面满足，K\* 即为全部平面。

以上结果全部写入 `protocol.json`。

### 6.4 预测

**第一层：冻结平面，还是整体漂移**

| 编号 | 量 | 冻结平面的预期 | H-drift 的预期 |
| --- | --- | --- | --- |
| HS1 | F{1} 单向 plus R\_2N（4 个域） | ≤ 0.20 | ≤ 0.20 |
| HS2 | F{1} 交替 R\_2N（weekday、month） | ≥ 0.80 | ≤ 0.20 |
| HS3 | F{1} 单向 plus 的复活（weekday、month） | A\_N ≥ 0.80，且 A\_⌈N/2⌉ ≤ 0.30 | A\_N ≤ 0.30 |

HS1 是两种假设共同的预测，用于确认在满秩算子上单独去掉基频就足以破坏组合。HS2、HS3 在两个域上都符合“冻结平面”的预期，才判为支持冻结平面。

**第二层：要保住哪些平面**

| 编号 | 量 | H-fund | H-complete | H-vote | 判定 |
| --- | --- | --- | --- | --- | --- |
| HS4 | F\_¬1 的单向 plus R\_2N（weekday F{2,3}、month F{2..6}、Z4 F{2}，共 4 个域） | 全部 ≥ 0.90 | 全部 ≤ 0.20 | 与锁定的 R̂ 类别一致 | 分别数三种假设吻合的域数，唯一达到 4/4 者胜出。H-fund 与 H-vote 预测相同的域记为“不区分” |
| HS5 | 单平面冻结 F{j}（j ≥ 2）的类别：weekday 2 格、month 5 格、compass 与 egoside 各 1 格，共 9 格 | 全部“可组合” | 全部“失败” | 锁定的类别 | 吻合 ≥ 7/9 的假设通过 |
| HS6 | 最小编辑器：在 dim(K\*) < N − 1 的域中，E\_{K\*} 三条路径的 R\_2N 都 ≥ 0.90，且同秩的 RRR-dim(K\*) 单向 R\_2N ≤ 0.20 | — | — | 成立 | 适用域中 ≥ 75% 成立为通过。门槛：该域 E\_all 三条路径都 ≥ 0.90，否则该域不可评 |

## 14. 结果之后

| 结果 | 含义 | 下一步 |
| --- | --- | --- |
| HS1–HS3 通过，H-vote 成立，HS6 通过 | 解码器按谐波平面加权投票读出状态。最小二乘的低秩编辑按更新能量分配秩，而不是按读出权重分配，所以先丢掉解码器最看重的平面。可组合的条件是保住解码器看重的平面，最小可组合秩可以远低于 N − 1 | 投票加权的降秩回归作为实用编辑器；推广到多 token 属性和 time/person 原任务 |
| H-fund 成立，HV1 不优于“只用基频” | 结论简化为“基频决定可组合” | 同上，改用“基频优先”的秩分配 |
| H-complete 成立 | “谐波”一说降为“完整覆盖状态张成”，论文不再使用谐波措辞 | 回到“秩 N − 1”的表述 |
| HS2、HS3 失败（H-drift） | 冻结平面模型不成立，失败来自离流形漂移 | 重新分析 v2 的复活现象，看它是否只在 RRR 秩不足时出现 |
| B′ 为 H-bind | 逐 token 线性编辑器做不了依赖绑定的编辑，person 的失败得到解释 | 跨 token（注意力式）编辑器的小实验 |
| B′ 为 H-geom | 绑定不是原因 | person 的失败另查：多 token、长度变化 |
| B′ 为 H-list | 名单语境中的名字本身不稳定 | 换名字集合与位置做对照 |
| N 为 H-state | CE 的不可组合来自解码器可执行的原生运算 | 机制一节写成“CE 学会调用解码器的原生运算” |
| N 为 H-token | CE 不会写入状态 | 规范监督（C3/RRR）是必要条件 |
| T 复现 | 结论跨骨干成立 | 开始写论文 |
| T 不复现 | 结论标明为 BART 特有 | 比较两个骨干的投票权重，以及指令调优的影响 |

论文主线（暂定）：**解码正确不等于可组合，取决于两件事：写入了什么（指令还是状态），以及保住了什么（解码器读取的谐波平面）。** 绑定与跨骨干两条决定适用范围。

## 附录 A：定义

### A.1 谐波平面、a\_k 与 s\_k（只用于循环域）
1. 在模板 0 的属性槽位，取每个 train world 的规范槽位表示，在 world 内去均值，再对 world 取平均，得到 c̄(x)。x 按自然顺序编号；X3 中按 σ 顺序编号。
2. 对 k = 1 … ⌊N/2⌋，令 u\_k = Σ\_x cos(2πkx/N)·c̄(x)，v\_k = Σ\_x sin(2πkx/N)·c̄(x)。按 k 从小到大做 Gram–Schmidt 正交化，得到 B\_k（d × 2；N 为偶数时 k = N/2 为 d × 1）与 P\_k = B\_k B\_kᵀ。P\_¬k 为其余全部平面的投影。
3. a\_k² = (1/N) Σ\_x ‖B\_kᵀ c̄(x)‖²。
4. s\_k = train 上 world 与 x 的平均 ‖B\_kᵀ (c\_w(x+1) − c\_w(x))‖，即一步更新在平面 k 上的幅度。

### A.2 投票模型
- 槽位向量 h（属于 world w）与候选状态 y 的平面距离：d\_k(h, y) = ‖B\_kᵀ(h − c\_w(y))‖²，c\_w(y) 为该 world 中状态 y 的规范槽位表示。
- 得分 S(y) = −Σ\_k λ\_k d\_k(h, y)；P(y | h) = softmax\_y S(y)；λ\_k = softplus(θ\_k)。
- 拟合：在可解析的探针上最小化平均负对数似然。用 L-BFGS，初值 λ\_k = 1 / median d\_k(c(x), c(x+1))，重启 5 次（种子 3101），取最好的一次。
- 报告归一化票力 ω\_k = λ\_k·E[d\_k(c(x), c(x+1))] / Σ\_j λ\_j·E[d\_j(c(x), c(x+1))]。
- 对照模型：等权（λ\_k 全部相同，只拟合一个参数）；只用基频（k ≥ 2 时 λ\_k = 0）。
- 预测：ŷ = argmax\_y S(y)。
- 理想化链：第 t 步的目标为 g\_t，起点为 x\_0。槽位向量为 h\_t = c\_w(g\_t) + Σ\_{k ∈ 冻结} P\_k (c\_w(x\_0) − c\_w(g\_t))。F\_S 的冻结集合为 S；E\_K 的冻结集合为 K 的补集。
- R̂：在 dev 的 world × 全部起点 x\_0 上，计算“所有 t ≤ 2N 都有 ŷ\_t = g\_t”的比例；plus、minus、交替分别计算。

### A.3 冻结手术与平面编辑器
- 冻结与平面编辑都只作用于槽位位置（模板 0 的槽位位置在域内恒定；T5Gemma 为包装后的位置）。
- F\_S 中，算子对平面 S 坐标的输入照常进入其他方向的更新（交叉项保留），只去掉平面 S 内的更新。
- E\_K 用 K 内平面坐标的联合最小二乘拟合（dim(K) × dim(K) 矩阵加偏置）。训练对为 train 上 (x, x+1)（plus）与 (x, x−1)（minus）。

### A.4 A\_t 与 R\_t
- A\_t：第 t 步输出判为成功的 world 比例，不管之前各步是否成功。
- R\_t：前 t 步全部成功的 world 比例，即 v2 的 R\_k。

### A.5 M4 移植的分类
同一 world 内，把源状态 x 的 C1 写入加到 x′ ≠ x 上并解码，结果分为：
- “相对”：输出 σ(x′)，且非目标事实保持（这一类即 v2 意义上的成功）；
- “绝对”：输出 σ(x)；
- “无效”：输出 x′；
- “自然后继”：输出 x′ 的自然后继（只在它不等于 σ(x′) 时计入）；
- “其他”与“不可解析”。

### A.6 合成自检（锁定前必须通过）
构造合成的 Z\_N 表示：c(x) = Σ\_k a\_k [cos(2πkx/N)·e\_{k,1} + sin(2πkx/N)·e\_{k,2}] + 噪声（σ = 0.01），d = 64，e 为随机正交基。T 为精确旋转算子。检查：
1. `planes()` 恢复出的平面与真值的主角度 < 1°。
2. F{k} 使平面 k 保持不变（误差 < 1e-6），其余平面被精确旋转。
3. 在合成训练对上拟合的 E\_K 精确旋转 K 内平面（误差 < 1e-4），其余平面不变。
4. 用已知 λ 模拟解码器生成探针，投票模型恢复出的 ω 与真值之差 < 0.05。
5. 在合成理想化链上，模型 argmax 与模拟解码器的一致率 ≥ 0.99。

### A.7 重建闸门
reencode 指对 train 与 dev 中每个 world 的每个状态，把规范文本编码后直接解码（不经编辑器）。成功按评测器对金标准的 `success` 判定。对每个（骨干，域，模板）组合，在 train+dev 合计上要求 ≥ 0.99。

### A.8 解析解码状态
在输出的属性句中找该域的状态词（bind3、bind3fix 为人名）。恰好找到一个时取为解码状态；找到零个或多个时记为不可解析。不可解析的比例单独报告。
