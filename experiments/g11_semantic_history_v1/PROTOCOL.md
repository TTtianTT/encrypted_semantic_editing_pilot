# G11: Semantic History and Continuability

Frozen before new-world model outputs. Baseline: b07abb4244415fea501cdb064bd9137a4db04587. No training, G12, fragility scans, new ranks, backbones or parser changes.

Question: with the same world, current frame and exactly the same correct current decoded text, do canonical encoding, one prior T_plus and two prior T_plus edits have equal next-step success? Three G10 rank16 editors, seeds 42/43/44, are retained irrespective of historical third-step performance. G3/G10 already used two-stage supervision; that is not a proposed new method.

Generate 80 fresh IID and 80 fresh template-OOD recorded_plan worlds, first-person, balanced polarity and template families. Reuse the original fact/date grammar. Seed 2026093017, split seed +1. Deduplicate the full fact key against all available historical world files; IDs/templates are not part of the key. Main anchor offset -1, secondary -2. Check all source/prefix/target dates before inference and mark structural N/A without replenishment. All required T_plus source offsets lie in the existing [-3,3] range; this does not imply these worlds were trained on.

For anchor d, H0=E(render(w,d)), H1=T(E(render(w,d+1))), H2=T(T(E(render(w,d+2)))). Preserve each history's original mask; never decode/reencode it. Save source reconstruction and every edited prefix. The current target is render(w,d) for all histories; the next target is render(w,d-1).

Two stages: current states and full FP32 latent shards first; lock strict/semantic cohorts and all shard/output hashes before any next-step inference. Strict: all three current outputs end normally and equal the single renderer target after stripping only boundary whitespace. Semantic: all current states pass the frozen scorer, including strict. Prefix-clean: all edited prefix steps pass (H0's current reconstruction must pass). Next stage applies T_plus to every legal history, including outside both cohorts. Resume from completed hash-checked shards. Never select by next-step outcome.

Primary comparison: main-anchor strict-cohort S0-S2, separately by seed and IID/OOD. Secondary: S0-S1, offset -2, prefix-clean, semantic cohort, and cross-seed-common-world sensitivity. Report predefined/legal/strict/semantic/equal-mask counts, all-denominator current/exact/next/full-history success, errors/unresolved/end failures, paired win/loss tables. Cluster bootstrap at world level, 2000 paired draws per split, jointly resampling seed/history/anchor observations. Seed mean/range is separate; bootstrap is conditional on these three trained editors.

Main-anchor 2x2 crossover on every strict H0/H2 pair with identical shape and elementwise mask: rc=T(H0)-H0, re=T(H2)-H2; Zcc=H0+rc, Zee=H2+re, Zec=H2+rc, Zce=H0+re. Same decoder/mask/target; no norm rescaling or alignment. Check re-rc = UV(H2-H0) over valid tokens with float32 tolerance. Equal shapes/masks do not establish token-semantic alignment. Report all four rates, Zec-Zee and Zce-Zee, rescue counts conditional on Zee failure, and interactions. Interpret computational component replacement, not a unique neuron or decoder-only mechanism.

Preflight uses only six existing G10 worlds: archived text/end agreement for all three seeds, repeated decoding, reversed/one-element batch layout, frozen weights and gradient absence, padding identity and checkpoint hashes. Generation stays raw BART input, fixed 96 padding, FP32, eval, greedy beam1, max_new_tokens60, no forced EOS. No target hints or gold bypass in ordinary histories.

Resource hard cap: 7200 total allocated GPU seconds, at most one GPU. sbatch+srun on B300q. Track allocations once per parent/task (not steps), including failures. Each GPU stage requests at most 30 minutes and has a 27-minute software deadline with saved shards. Do not submit another job if its requested limit would exceed the remaining total budget. Large activations are local-only with hashes; small editor weights are reused rather than republished.

Decision rules: strict N<40 means insufficient coverage; canonical next success<90% means inadequate single-step state support. Strong continuation evidence requires IID mean Delta2>=15pp, all three seeds same direction, paired world CI excluding zero, and at least two OOD seeds same direction. Anchor-specific results remain state-specific. No automatic G12 regardless of outcome. Blind case IDs fixed before outputs; human labels remain blank absent actual human review.

Deliver protocol/config/data/cohort lock, current/next/crossover raw outputs, paired summaries/statistics, blinded examples, source/checkpoint/latent hashes, audit, budget, commands and REPORT.md. Preserve all earlier experiments and publish only this directory on experiment/g11-semantic-history-v1 under existing session authorization.
